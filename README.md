# Стеклофурнитура — новая версия сайта

Светлый архитектурный редизайн сайта https://www.steklofurnitura.by/.
Исходные страницы, артикулы, характеристики, фотографии, документы и контакты перенесены из публичного сайта. Дизайн адаптирован для телефонов.

## Структура

- `dist/`: готовый статический сайт; раздавать с сохранением путей файлов.
- `scripts/static/style.css`, `scripts/static/app.js`: исходники общей дизайн-системы и поведения; генератор копирует их в `dist/`.
- `dist/products.json`: индекс товаров для поиска и заявки.
- `scripts/build.py`: генератор страниц из снимка исходника.
- `scripts/collect.py`: возобновляемое чтение исходных страниц.
- `scripts/assets.py`: перенос изображений и документов, оптимизация изображений в WebP.
- `scripts/verify.py`: проверка сохранности исходных полей/текстов, контактов, адресов, внутренних ссылок и ресурсов.
- `research/inventory.json`: список исходных URL и статус чтения.
- `research/source-snapshot.json.gz`: снимок исходных страниц для воспроизводимой сборки.
- `research/media-map.json`: сопоставление исходных ресурсов локальным файлам.

Для сборки нужны Python 3, lxml и Pillow. Если `research/pages` отсутствует, генератор восстановит его из снимка.

```sh
python scripts/build.py
node --check scripts/static/app.js
node --check dist/app.js
python scripts/verify.py
```

Визуальное обновление от 09.11.2026 использует единую бело-оранжевую систему, адаптивную навигацию, доступные состояния управления и увеличение фотографий. Изменяйте шаблоны в `scripts/build.py` и общие ресурсы в `scripts/static/`, затем пересобирайте сайт; ручные изменения сгенерированных файлов не являются исходниками.

## Заявки и обновление каталога

Список заявки хранится в браузере. Кнопка «Подготовить письмо» открывает почтовую программу посетителя с выбранным менеджером и заполненным списком. Отправку выполняет посетитель; серверная отправка в старую CMS не подключена.

Каталог является снимком исходного сайта на дату переноса. Для рабочего запуска нужно подключить редактирование каталога/остатков и серверную отправку к действующей системе компании, затем настроить домен. Оригинальный сайт не изменён.

Изображения оптимизированы до 1600 px; содержимое документов сохранено. Крупные технические PDF доступны на сайте по исходным ссылкам, а их полные копии сохранены в `reference-documents/`; это позволяет уложить пакет публикации в лимит 256 MiB. Основной каталог 2023 года остаётся локальным. Видео и внешние сервисы доступны по исходным ссылкам. Отсутствующие на исходном сервере файлы перечислены в `research/asset-errors.json`.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` публикует содержимое `dist/` по адресу
https://steklofurniturasite.github.io/steklofurnitura/.
Он запускается при изменении сайта в `main` и вручную через Actions.

GitHub Pages уже настроен на публикацию через GitHub Actions. Для новой копии
репозитория выберите Settings → Pages → Build and deployment → Source → GitHub Actions.
Текущая версия успешно опубликована и проверена 09.11.2026: [отчёт и контрольные снимки](docs/visual-redesign-report.md).

Скрипт `python3 scripts/prepare_github_pages.py` создаёт отдельный каталог
`.github-pages/` и адаптирует абсолютные локальные ссылки под `/steklofurnitura/`.
Исходный `dist/` сохраняется для размещения на собственном домене.

Технические проверки перед публикацией: `bash scripts/check.sh`.
Публикация выполняется только после `validate`, включая браузерную регрессию.
Инструкция по резервному копированию и откату: [docs/design.md](docs/design.md).
