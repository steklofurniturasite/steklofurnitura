# Стеклофурнитура — новая версия сайта

Светлый архитектурный редизайн сайта https://www.steklofurnitura.by/.
Исходные страницы, артикулы, характеристики, фотографии, документы и контакты перенесены из публичного сайта. Дизайн адаптирован для телефонов.

## Структура

- `dist/`: готовый статический сайт; раздавать с сохранением путей файлов.
- `dist/products.json`: индекс товаров для поиска и заявки.
- `scripts/build.py`: генератор страниц из снимка исходника.
- `scripts/collect.py`: возобновляемое чтение исходных страниц.
- `scripts/assets.py`: перенос изображений и документов, оптимизация изображений в WebP.
- `scripts/verify.py`: проверка сохранности исходных полей/текстов, контактов, адресов, внутренних ссылок и ресурсов.
- `research/inventory.json`: список исходных URL и статус чтения.
- `research/source-snapshot.json.gz`: снимок исходных страниц для воспроизводимой сборки.
- `research/media-map.json`: сопоставление исходных ресурсов локальным файлам.

Для сборки нужны Python 3, lxml и Pillow. Если `research/pages` отсутствует, генератор восстановит его из снимка.

```sh
python scripts/build.py
node --check dist/app.js
python scripts/verify.py
```

## Заявки и обновление каталога

Список заявки хранится в браузере. Кнопка «Подготовить письмо» открывает почтовую программу посетителя с выбранным менеджером и заполненным списком. Отправку выполняет посетитель; серверная отправка в старую CMS не подключена.

Каталог является снимком исходного сайта на дату переноса. Для рабочего запуска нужно подключить редактирование каталога/остатков и серверную отправку к действующей системе компании, затем настроить домен. Оригинальный сайт не изменён.

Изображения оптимизированы до 1600 px; содержимое документов сохранено. Видео и внешние сервисы доступны по исходным ссылкам. Отсутствующие на исходном сервере файлы перечислены в `research/asset-errors.json`.
