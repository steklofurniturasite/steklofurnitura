# План визуальной модернизации

Основание — ТЗ от 09.11.2026, самостоятельная реализация утверждённой бело-оранжевой концепции.

1. Зафиксировать исходную версию, каталог и браузерные снимки; создать отдельную ветку.
2. Обновить общие шаблоны и единый CSS: главная, шапка, каталог, товары, информация, контакты, заявка и футер.
3. Улучшить интерфейсные состояния и доступность существующих JS-механизмов без изменения способа отправки заявки.
4. Воспроизводимо собрать все страницы из исходного снимка; проверить данные и внутренние ссылки.
5. Проверить страницы и функции в Chromium, мобильные размеры и пакет GitHub Pages; исправить найденное.
6. После успешных проверок перенести проверенную версию в main, дождаться GitHub Actions и проверить опубликованный сайт.
