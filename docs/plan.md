# План реализации

1. Собрать все страницы из sitemap и публичной навигации, сохранить снимок для сверки. Проверка: журнал URL без потерянных страниц.
2. Извлечь каталог, контакты, проекты, статьи и документы; сохранить исходные формулировки. Скопировать используемые изображения.
3. Создать общие шаблоны и архитектурную главную страницу. Реализовать каталог, карточки товаров, поиск по названию/артикулу, мобильную навигацию, список заявки и выбор менеджера.
4. Сгенерировать адреса исходных страниц. Проверить внутренние ссылки, индекс товаров и сохранность исходных данных; визуально проверить широкую и мобильную версии.
5. Сохранить исходники и опубликовать отдельную частную версию для просмотра.
