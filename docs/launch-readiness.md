# Каталог и SEO перед рабочим запуском

## Каталог

Категории до 30 товаров сохраняют прежнюю структуру. Большие категории содержат первые 30 карточек и настоящие ссылки на статические страницы по 30 товаров. Все карточки доступны без JavaScript; страницы включены в sitemap. С JavaScript «Показать ещё» добавляет порции, сохраняя прежние DOM-узлы. Память загрузки общая с существующим products.json; поисковые метаданные не запрашиваются для каталога. Членство категории и подтверждённый бренд загружаются отдельным компактным JSON только при взаимодействии. URL содержит хеш содержимого для обновления кеша. Данные товаров, цены и поиск не изменены.

Сортировка использует весь набор до пагинации и сохраняет выбор в sessionStorage. Фильтры используют реальные бренды и непустую отделку. Сброс сохраняет сортировку. Ошибка загрузки сохраняет исходные карточки, статическую навигацию и возможность повторить запрос.

Замер крупнейшей категории: [данные до/после](catalogue-size.json). Начальных карточек 481 → 30; HTML 635857 → 64858 байт; gzip 30893 → 8696 байт. Это измерение размера/DOM, не Lighthouse или полевые Core Web Vitals. Lighthouse в окружении недоступен; Performance ≥90 и Accessibility ≥95 не заявляются.

## SEO

Единственный источник настройки: `scripts/site_config.json`.

Сейчас `indexingEnabled:false`, `siteOrigin:https://steklofurniturasite.github.io`, `basePath:/steklofurnitura`. На всех HTML есть `noindex,follow`; robots.txt не запрещает чтение страниц и не рекламирует sitemap. Canonical/OG URL указывают на техническую preview-версию, не объявляют GitHub официальным доменом компании. На GitHub Pages project robots.txt находится под путём проекта и не управляет robots.txt всего github.io-домена; главным ограничением служит meta noindex каждой страницы. Аналитика, Search Console и отправка sitemap не подключались.

После согласования рабочего домена владелец меняет siteOrigin на подтверждённый origin без пути, basePath на пустую строку для корня либо согласованный подпуть и отдельно включает indexingEnabled. Пересборка создаёт новые canonical, метаданные, JSON-LD, sitemap и robots со ссылкой на sitemap. Включение индексации на github.io блокируется проверкой. Подготовка Pages и проверка маршрутов берут базовый путь из той же конфигурации. CI проверяет браузерные сценарии на отдельной preview-копии с привычным путём проекта, если рабочая конфигурация использует корень или другой путь; опубликованный артефакт при этом сохраняет рабочие пути. Технические страницы/поиск/корзина остаются noindex и исключены из sitemap даже в рабочем режиме. Sitemap не содержит lastmod, дубликаты или вымышленные даты.

Метаданные используют реальные названия, артикулы, отделку и хлебные крошки. JSON-LD Organization/BreadcrumbList/Product не содержит выдуманных offers, остатков, рейтингов или отзывов. Два режима, корень и подпуть проверяются локальными тестами без внешних SEO-сервисов.

## Достоверность и документы

Универсальная гарантия «12 месяцев» заменена ссылкой на сохранённые условия: архивная страница условий содержит исключения, в том числе для масляных доводчиков. Универсальная доставка заменена ссылкой на оплату/доставку: архивный материал описывает получение на складе и доставку через перевозчика с включением стоимости в счёт. Неподтверждённые цены сохраняют «Цену уточняйте»; нейтральный текст не обещает актуальную числовую цену.

Исправлена пустая основная фотография некоторых товаров: если архивная ссылка полноразмерного фото не имеет сохранённого файла, показывается уже существующая фотография того же товара из каталога. Исходные записи/фотографии не меняются.

В архиве один PDF products.dorma.com отмечен HTTP 503; при HEAD из среды проверки URL вернул 403. Он не подменяется другим документом. Возле соответствующего материала есть подсказка запросить документ у компании. Шесть сохранённых внешних PDF официального каталога ответили HTTP 200 на HEAD-проверку. Запасной маршрут Яндекс Карты сохранён независимо от iframe.

## Проверки и необходимые согласования

Штатная сборка проверяет все 1463 товара, неизменность исходных полей/цен и внутренние ссылки. Новые seo_checks.py и catalogue_checks.cjs включены в обе существующие CI-цепочки. Для сортировки прежние браузерные проверки дожидаются асинхронного обновления всей категории, сохраняя исходные утверждения. Архив research не перезаписывается; текущие результаты статической проверки выводятся в CI.

Перед рабочим запуском компания должна подтвердить домен и миграцию, порядок обработки персональных данных/утверждённые документы и актуальный внешний PDF DORMA. Настройки реальных почтовых получателей и активация FormSubmit — отдельное согласованное действие: сейчас testMode:true, оба типа заявок только на steklofurniturasite@gmail.com. Реальная доставка/CAPTCHA по-прежнему требуют проверки владельцем; автоматические тесты мокируют отправку.
