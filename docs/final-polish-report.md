# Финальная визуальная полировка «СтеклоФурнитура»

9 ноября 2026. Исходная версия c5d6631; резервная ветка
[backup/pre-final-polish-2026-11-09](https://github.com/steklofurniturasite/steklofurnitura/tree/backup/pre-final-polish-2026-11-09).
Разработка: [design/final-polish](https://github.com/steklofurniturasite/steklofurnitura/tree/design/final-polish).

## Изменения и основания

- Композиция hero: умеренно скорректированы соотношение колонок, интервал и межстрочный
  ритм заголовка. На телефоне сокращены интервалы текста/статистики, фотография ближе
  к действиям. Высота hero на 375 px: 866 → 810 CSS px. Снимок «Галилео» сохранён.
- Категории: более спокойная горизонтальная пропорция фотографий на широких экранах;
  существующая адаптивная сетка и полные названия сохранены.
- Товары: цена и кнопка расположены в первой строке, примечание — во второй на всю
  ширину. Это устраняет сжатие и чрезмерные переносы примечаний в двух колонках.
  Область фото немного компактнее на телефоне, сами товары не растянуты и не обрезаны.
- Каталог: компактнее toolbar и select, количество и сортировка помещаются рядом
  при обычной ширине телефона. Названия/артикулы не сокращались.
- Страница товара: аккуратнее промежутки миниатюр и высота главного фото на телефоне;
  ширина технического описания ограничена 82ch; таблицы сохраняют собственную прокрутку.
- Реальные проекты: полные фотографии с `contain` вместо обрезания архитектуры,
  нейтральное поле вокруг портретных кадров; оригиналы и галерея доступны.
- Навигация/детали: увеличена вертикальная область мобильных ссылок футера,
  лёгкие анимации меню и уведомления, отключаемые reduced-motion.
- Контакты: iframe заменён локальной Leaflet 1.9.4. Светлая приглушённая подложка,
  оранжевый маркер, масштаб, перемещение, «К офису», адресная карточка и настоящая
  кнопка маршрута. Координаты 53.945793, 27.682951 сохранены из прежней карты;
  точка склада отдельно не придумывалась.

Качественные существующие решения оставлены: палитра #c54908/белый/графит,
системный шрифт, шапка, структура разделов, реальные изображения и тексты,
карточки контактов, состав рекомендуемых товаров, логика заявки и поиска.
Информационные страницы используют общие улучшения и проверены без создания
новых отдельных стилей. Серверная отправка, CRM и другие функции не добавлялись.

## Карта, лицензии и отказоустойчивость

[Leaflet 1.9.4 API](https://leafletjs.com/reference-1.9.4.html), лицензия BSD-2-Clause
сохранена рядом с локальными файлами. Библиотека и код карты подключаются только
в контактах, тайлы — при попадании карты в видимую область.

[Политика OSM Standard](https://operations.osmfoundation.org/policies/tiles/):
точный HTTPS endpoint, обычные browser User-Agent/Referer, кеширование по заголовкам,
без принудительного no-cache, фонового prefetch, offline-выгрузки или скрытой атрибуции.
Видно © OpenStreetMap contributors. Бесплатный сервис не гарантирует SLA.
Кнопка маршрута и адрес доступны при отказе тайлов или библиотеки.
Автоматические zoom/pan тестируются на заглушке тайлов, чтобы не нагружать OSM.
Подложка также открыта для визуальной проверки без автоматического сканирования.

## Проверки

- `scripts/check.sh`: Python/JS, сборка, сверка исходного содержания, полей,
  описаний, контактов, маршрутов и подготовленного пакета — без ошибок.
- Все прежние поля **1463 товаров**, включая цены и остатки, совпадают с SHA-256
  исходного каталога. 1641 HTML-страница пересобрана. Проверены **147419** ссылок
  подготовленного пакета; служебные ресурсы Leaflet сохраняются без переписывания.
- Браузер: восстановление поиска после 503, название/артикул/нет результатов,
  три товара в заявке, количество, удаление, сохранение после обновления,
  копирование и открытие корректных товарных ссылок — PASS.
- Дополнительные сценарии: сортировка, галерея/миниатюры/диалог/Escape,
  мобильное меню/возврат фокуса, reduced-motion, zoom/pan/reset/маршрут,
  атрибуция и fallback карты — PASS. Регрессия карты добавлена в GitHub Actions.
- **108 компоновок:** 12 типов страниц × 9 ширин: 320, 360, 375, 390, 430,
  768, 1024, 1440, 1920 px. Переполнения страницы не обнаружены.
- Контрольные снимки главной, каталога, товара, контактов, пустой заявки,
  проектов и поиска сняты до/после на 375/1440 px. Пары просмотрены; исправлен
  один некорректно снятый локальный кадр при пересоздании пакета, затем переснят.
  Это ошибка QA-сервера во время копирования файлов, а не оставленный дефект сайта.

Машинные результаты: [до](final-polish/before/audit.json),
[после](final-polish/after/audit.json), [UI](final-polish/ui-checks.json).
В первом проходе ошибочно запрашивался `/info/katalogi.html`; проверка исправлена
на действительный `/info/dokumenty.html`. Ошибка пути проверки не приписана сайту.

## Оценка и ограничения

Это субъективная оценка контрольных страниц в Chromium, не формальный рейтинг
и не обещание 10/10 на каждом устройстве.

| Направление | Оценка | Обоснование / ограничение |
|---|---|---|
| Главная | 9.2 | Сохранена сильная композиция, мобильный hero компактнее |
| Каталог | 9.1 | Полные названия и единый ценовой блок; длинные категории остаются длинными |
| Карточка товара | 9.2 | Ясные действия и читаемое описание; исходные фото неодинакового разрешения |
| Мобильная версия | 9.0 | Девять контрольных ширин; реальные iOS/Android отдельно не тестировались |
| Типографика | 9.1 | Общая шкала, улучшение интервалов; системная гарнитура |
| Цветовая гамма | 9.4 | Сохранён фирменный оранжевый и нейтральные поверхности |
| Композиция | 9.1 | Меньше лишней высоты, полные проектные кадры |
| Навигация | 9.1 | Сохранена знакомая структура; меню и клавиатура проверены |
| Контакты | 9.3 | Реальные сведения, маршрут и независимый адресный блок |
| Карта | 9.0 | Брендирование и управление; OSM зависит от внешней доступности |
| Визуальная согласованность | 9.2 | Общие компоненты на всех сгенерированных страницах |

Общие CSS+JS в gzip выросли примерно на **591 байт**; карта добавляет около
**47 КБ gzip только в контактах**, без внешних шрифтов. Это размеры файлов,
не измерение времени загрузки. Lighthouse и полевые Core Web Vitals не измерялись;
полное соответствие WCAG 2.2 AA не заявляется. Предыдущее ограничение старого
внешнего PDF products.dorma.com остаётся; данные и документы не удалялись.

Публикация — только после успешных проверок существующим защищённым workflow.
Для отката: git revert коммита полировки в отдельной ветке, проверки и слияние;
исходное состояние доступно в резервной ветке. Принудительный push не требуется.
