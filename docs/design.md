# Дизайн сайта «Стеклофурнитура»

Актуальная концепция пользователя от 09.11.2026: современный корпоративный премиум в бело-оранжевой гамме. Белый — основной фон, светло-серый — второстепенные поверхности, графитовый — текст и контраст, оранжевый — действия и фирменные акценты. Декоративные синие, бирюзовые, фиолетовые и золотые акценты исключены.

Детали реализации и критерии проверки: [спецификация визуальной модернизации](superpowers/specs/2026-11-09-premium-redesign.md).

Настоящие фотографии проектов, товаров, исходные технические сведения и структура URL сохраняются. Шрифты системные, без внешних запросов. Воспроизводимая статическая сборка: шаблоны в scripts/build.py, исходники общих стилей и поведения в scripts/static/. Каталог, поиск и localStorage-заявка работают по существующим принципам, отправка — через mailto и копирование.

## Техническая стабилизация 09.11.2026

Архитектура: исходные HTML и данные снимка хранятся в `research/source-snapshot.json.gz`;
`build.py` восстанавливает их и генерирует `dist/`, копируя общие CSS и JS из `scripts/static/`.
`prepare_github_pages.py` создаёт отдельный пакет `.github-pages/` с проектным префиксом.
Канонический `route` в индексе сохраняется без префикса, `url` и `image` адаптируются
только для навигации. Ссылка заявки строится из текущего origin, базы сайта и `route`;
официальный домен не подставляется принудительно. При переносе на собственный домен
используйте `dist/` или подготовку с `--base-path ''`.

Цены, прежние цены и исходные остатки сохранены без изменений. Отображаемое наличие
требует подтверждения менеджером; сохранённая цена сопровождается оговоркой,
старые скидки не рекламируются. Поля `price`, `oldPrice`, `stock`, `article`, `route`
сохранены для будущего импорта из Excel; сам импорт в этом этапе не реализован.

Сброс неуспешного Promise и кнопки повторной попытки уже присутствовали в актуальном
коде; проверены реальной сетевой ошибкой 503 и успешной повторной загрузкой.
Список подозрительных ссылок проверен отдельно в `research/link-review.json`:
21 существующий локальный адрес, две канонические замены и внешнее видео HTTP 200.
Не существующие старые URL не используются в новых ссылках.

Проверки (Python 3.12, Node.js, `lxml==5.4.0`):

```sh
bash scripts/check.sh
```

Скрипт проверяет синтаксис Python/JS, пересобирает сайт, сверяет исходное содержание,
каталог, контакты, все внутренние ссылки и подготовленный пакет Pages. SHA-256
`research/catalog-baseline.sha256` фиксирует все прежние поля всех 1463 товаров,
включая цены/остатки. При санкционированном обновлении каталога базовую сумму меняют
только после проверки новых данных; для обхода теста её не обновляют.

Браузерная регрессия (`scripts/browser_checks.cjs`, Playwright) проверяет сетевое
восстановление, поиск, корзину, ссылки заявки и основные страницы при 375/1440 px.
Для локального запуска поднимите сервер подготовленного сайта по адресу
`http://127.0.0.1:8000/steklofurnitura/`, установите Playwright и Chromium, затем
`CHROMIUM_PATH=/usr/bin/chromium node scripts/browser_checks.cjs`.
Можно задать `TEST_ORIGIN`, `TEST_BASE`, `SCREENSHOT_DIR`.

Безопасная публикация: работайте в отдельной ветке, сохраняйте резервную ветку,
запускайте проверки. Workflow сначала выполняет независимый job `validate`, включая
браузерные сценарии и отрицательный тест удаления обязательного файла. Job `deploy`
зависит от успешного `validate` и разрешён только для `main`, вне pull request.
После слияния проверяйте успех Actions и опубликованные страницы.

Восстановление: исходная стабильная версия находится в ветке
`backup/pre-technical-fixes-2026-11-09` (8582a0c).
Для штатного отката создайте ветку из main, выполните `git revert` коммита
технических исправлений, проверьте восстановленный код и перенесите откат в main;
прежний workflow опубликует прежний сайт. Не применяйте force push.
Для аварийного восстановления можно повторно развернуть сохранённый успешный
artifact Pages через прежний workflow, пока artifact доступен.

Результат локальной проверки: все 1463 товара и прежние поля совпадают;
1639 исходных маршрутов, 4276 полей и 4499 фрагментов описаний сохранены;
147416 подготовленных ссылок проверены. Браузер: поиск по названию/артикулу,
пустая выдача, 503 и повтор, 3 ссылки заявки (включая SR-670 32x325x500 SSS),
количество/удаление/сохранение корзины, 12 адаптивных представлений, изображения
и отсутствие новых JS-исключений. Отдельно проверена ссылка заявки на корне домена.

Технические PDF: шесть крупных руководств на исходном сервере проверены HTTP 200,
копии сохранены в `reference-documents/`. Старый внешний `products.dorma.com/.../0403 ul light.pdf`
возвращает HTTP 403; его содержимое не подменялось. Результаты — `research/document-review.json`.
CI закреплён на Ubuntu 24.04: переход `ubuntu-latest` на 26.04 несовместим с
системными зависимостями закреплённой версии Playwright 1.58.2.

## Финальная полировка

Сохранены существующая концепция и фактические данные. Уточнены пропорции hero,
карточек и проектных кадров, ценовой блок, мобильные интервалы и toolbar.
Карта контактов: локальная Leaflet 1.9.4 + OSM Standard с видимой атрибуцией,
загрузкой по видимости и независимым адресом/маршрутом. Условия и контрольные
снимки: [отчёт финальной полировки](final-polish-report.md).
Новый `scripts/map_checks.cjs` входит в браузерные проверки Actions.

По последующему запросу пользователя карта контактов заменена на Яндекс Карты.
Используется lazy iframe с прежними координатами 53.945793, 27.682951;
адресная карточка и кнопка маршрута сохранены. Leaflet на странице не подключается.
