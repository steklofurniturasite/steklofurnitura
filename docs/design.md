# Редизайн «Стеклофурнитура»

Цель: полностью обновить визуальное оформление steklofurnitura.by, сохранив тексты, товары, артикулы, характеристики, изображения, документы и контактные сведения исходного сайта.

Выбранный пользователем стиль: светлый архитектурный. Белый и светло-серый фон, графитовая типографика, синие акценты, реальные фотографии проектов. Альтернативы: тёмная имиджевая версия и компактная техническая версия.

Главная страница: крупная архитектурная композиция, каталог по направлениям, рекомендуемые товары, реальные проекты, преимущества, статьи, сведения о компании и контакты. Внутренние страницы: общее оформление, хлебные крошки, навигация, карточки товаров и читаемые информационные материалы. Мобильная версия обязательна.

Решение исполнителя: статическая генерация страниц на основе снимка исходного публичного сайта. Это сохраняет адресную структуру и позволяет проверить полноту переноса. Поиск выполняется локально по индексу товаров, заявка собирается в браузере и передаётся через почтовую программу пользователя выбранному менеджеру. Прямую отправку в старую CMS без доступа к ней не имитировать.

Новую версию разместить отдельно для просмотра. Исходный домен и работающий сайт не изменять.
