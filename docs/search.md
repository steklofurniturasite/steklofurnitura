# Поиск товаров

Поиск работает целиком в браузере. `scripts/static/search.js` — общий алгоритм для подсказок и результатов; `app.js` управляет интерфейсом. `build.py` генерирует отдельные поисковые метаданные из существующих категорий и хлебных крошек, не меняя `products.json`.

Артикулы сохраняют значимые буквы и цифры. Нормализация объединяет регистр, пробелы, разделители (включая +) и х/x/× между цифрами; визуальные кириллические/латинские аналоги приводятся только в кодах с цифрами. Для обычных слов используются е/ё и небольшой словарь брендов и словоформ. Технические URL не участвуют в поиске. Порядок: точный артикул, нормализованный артикул, начало артикула, точное название, начало названия, слова названия, характеристики/категория/бренд. Равные результаты сохраняют исходный порядок; дубли не удаляются.

Подсказки: до 6 товаров, задержка 180 мс, стрелки/Enter/Escape, очистка, ARIA combobox/listbox. Результаты: по 30 карточек, «Показать ещё», количество и фильтры по доступным брендам/категориям. Старый `/system/search.html?q=…` использует ту же страницу и тот же код. Ошибки загрузки можно повторить, устаревшие ответы не заменяют новый запрос. Загрузка начинается при фокусе поля и перекрывает задержку ввода. Каталог и поисковый индекс загружаются/строятся один раз на страницу; повторяющиеся поля нормализуются с локальным кешем при построении индекса; корзина сохраняет собственную существующую логику.

Проверки:

```
bash scripts/check.sh
node scripts/search_checks.cjs
CHROMIUM_PATH=/usr/bin/chromium node scripts/search_browser_checks.cjs
```

Первый новый тест проверяет все 1463 артикула и варианты разделителей/регистра, дубли, семь уровней ранжирования, бренды, словоформы, размеры и ложные результаты. Второй — мобильный и настольный интерфейс, клавиатуру, пагинацию, фильтры, быстрый ввод, старый адрес, HTML-безопасность и повтор после 503. Оба включены в существующие GitHub Actions. Остальные браузерные и ценовые проверки сохранены.

Изменения предлагаются отдельным PR. Объединение с main и публикация требуют подтверждения владельца.

Первые подсказки проверяются на ширине 360 px с замедлением CPU ×4 и бюджетом 3 секунды (включая задержку ввода и локальную загрузку). Это лабораторная проверка, а не измерение мобильной сети или физического телефона.
