# Финальная визуальная полировка

Концепция и самостоятельная реализация утверждены ТЗ. Один агент; существующая
статическая архитектура, палитра и все данные сохраняются. Исходная версия c5d6631,
резервная ветка backup/pre-final-polish-2026-11-09.

Выбран подход точечных правок общих CSS-правил и генератора: сокращение отступов
hero на телефоне, улучшение пропорций категорий, отдельная строка примечания цены,
компактная сортировка, удобные миниатюры, читаемые описания и полные проектные фото.
Переписывание CSS и смена визуальной концепции не соответствуют задаче.
Качественные шапка, навигация, фон, фотографии и локальная заявка остаются основой.

Карта: локальная Leaflet 1.9.4 только в контактах, OSM Standard, без ключей и платы.
Координаты 53.945793,27.682951 — из прежнего виджета, без придумывания отдельной
точки склада. Адрес и внешняя маршрутизация независимы от карты. Тайлы запрашиваются
при видимости, без предзагрузки, с обычным browser Referer/cache и атрибуцией.
Тесты zoom/pan в автоматизации используют заглушку тайлов, а не OSM сервер.

Контроль: скриншоты до/после, основные типы страниц, девять ширин, исходный каталог,
ссылки, корзина, поиск, сортировка, галерея, меню, карта и отказоустойчивость;
защищённый workflow сохраняется. Субъективная оценка не заменяет проверки и не
означает сертификат WCAG или гарантированные Core Web Vitals.
