# Motion upgrade

Продолжение одобренного самостоятельного развития архитектурного дизайна; один агент.
Выбран лёгкий общий слой CSS + Web Animations API вместо библиотеки/параллакса:
короткий отклик 140–240 ms, перестановка 300 ms, появление 480 ms, фотографии 550 ms.
Данные, размеры компонентов, маршруты и бизнес-логика сохраняются.

Меню/уведомления/галерея открываются мягко. Закрытие состояния и возврат фокуса
мгновенные; краткий визуальный уход — inert/aria-hidden снимок без ID и действий,
автоматически удаляемый. Быстрые повторы отменяют прошлую анимацию. Галерея защищена
номером выбора от устаревших load-событий. Сортировка и удаление используют FLIP
только для видимых элементов, максимум 24; появления — максимум 96 наблюдаемых блоков.
Скрытого начального контента нет, отказ JS/WAAPI оставляет рабочую страницу.
Reduced-motion отключает эффекты, отменяет уже запущенные и удаляет снимки.

Проверки: реальные сценарии/быстрые повторы/клавиатура, включение reduced-motion
во время движения, отказ WAAPI и JS, настольная и мобильная версии, данные и ссылки.
После пересборки и успешных проверок — существующая защищённая публикация.
