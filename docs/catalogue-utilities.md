# Пять улучшений удобства каталога

- Кнопка рядом с артикулом копирует его без лишнего текста. Ошибка доступа к буферу сообщает о ручном копировании.
- В увеличенной фотографии горизонтальный свайп переключает изображения. Вертикальные жесты и масштабирование двумя пальцами не перехватываются.
- Выбранная сортировка сохраняется в текущей вкладке при переходах и перезагрузке. «По умолчанию» восстанавливает исходный порядок.
- Поиск выводит совпадение полного артикула первым; названия с «е» и «ё» находятся одинаково.
- Кнопка «Распечатать заявку» открывает системную печать, где можно выбрать сохранение PDF. Печатная версия сохраняет товары, количества, цены и контактные поля, убирает навигацию и управляющие кнопки.

Проверки: `bash scripts/check.sh`, 16 тестов синхронизации цен и браузерные сценарии `browser_checks.cjs`, `map_checks.cjs`, `motion_checks.cjs`, `price_checks.cjs`, `premium_checks.cjs`, `utility_checks.cjs`. Последний сценарий проверяет пять улучшений, отказ буфера обмена, вертикальный жест, сброс сортировки и формирование PDF. Он добавлен в обе цепочки GitHub Actions перед публикацией.

Данные всех 1463 товаров и подтверждённые ранее статусы цен сохранены. Новая сверка официальных цен не запускалась.
