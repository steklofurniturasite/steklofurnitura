# Автоматическая сверка цен

Источник: https://www.steklofurnitura.by/. Обрабатываются все 1463 существующих
товара. Источник структуры и содержимого — неизменяемый снимок
`research/source-snapshot.json.gz`; новый источник стоимости — `data/prices.json`.
Генератор применяет его до формирования любых карточек, рекомендаций и JSON поиска.
Сборка без полного проверенного файла цен запрещена.

## Правила

Каждый товар проверяется по своему точному URL и точному значению скрытого поля
артикула. Дополнительно сверяются видимая строка артикула и служебная ссылка товара.
Пробелы в видимой табличной строке нормализуются только для этой дополнительной
проверки; артикул из input сравнивается посимвольно. Названия не используются.
Повторяющиеся артикулы различаются по URL.

Число принимается только из видимой строки цены с подписью «Цена с НДС»/«Цена c НДС»
и валютой BYN. Зачёркнутые, старые, скрытые значения исключаются.
`verified` — подтверждённая числовая цена; `request` — официальное «Цену уточняйте»;
`unavailable` — официальный числовой блок скрыт, публичную цену подтвердить нельзя.
В двух последних случаях публикуется «Цену уточняйте» и null вместо числа.
Это отдельные состояния: скрытая цена не называется официальным текстом «Цену уточняйте».
Сетевой сбой, неправильный артикул, незнакомый шаблон, другая валюта/неясный НДС,
неожиданный редирект и конфликтующие цены — ошибки, блокирующие весь пакет.
Последний успешно опубликованный пакет при неуспешном запуске сохраняется.

В `prices.json` для каждой позиции: артикул, URL, состояние, целое количество
копеек или null, отметка НДС, UTC проверки и SHA-256 исходного ответа.
Публичные prices в JSON/HTML проверяются по этому файлу. Наличие товара не изменяется.
В корзине цены берутся из текущего products.json, а не из localStorage.
Суммы вычисляются BigInt в копейках. Если цена хотя бы одной позиции неизвестна,
итог — «Цену уточняйте», известная часть показывается отдельно и не называется итогом.
В копируемой/почтовой заявке те же цены и суммы. Это цены последней сверки;
стоимость и наличие при обработке заявки подтверждает менеджер.

## Запуск без ИИ

Python 3.12 + уже существующая зависимость lxml 5.4.0. Новых runtime-зависимостей нет.

```sh
python -m pip install lxml==5.4.0
# Полный предварительный просмотр, без записи цен:
python scripts/sync_prices.py
# Применить проверенный пакет из того же запуска (успешные ответы не старше 24ч):
python scripts/sync_prices.py --resume --apply
# Пересобрать и выполнить проверки:
bash scripts/check.sh
python -m unittest discover -s scripts/tests -v
```

Без `--resume` всегда выполняется новая полная сетевая сверка.
`--resume` — для продолжения того же запуска, не долгосрочный кеш цен.
При первой публикации сверка выполнена с минимальным интервалом 0.5 с между
последовательными запросами; регулярный запуск использует 1 с. Параллельного
обхода нет. Сначала проверяется robots.txt; его запреты и Crawl-delay/Request-rate
учитываются. При недоступном robots.txt обход не начинается.
Повторяются только временные сетевые ошибки, максимум 3 повтора с паузой;
учитывается Retry-After. 403/исчерпанный 429 или серия сетевых сбоев/ошибок разбора останавливает обход.
Не используются приватные API, обход авторизации и запрещённые robots пути.

`.price-sync/` содержит gzip-копию исходного products.json, прежний манифест цен,
checkpoint, полный кандидат, список изменений, ошибки, краткую статистику,
robots.txt и gzip HTML-доказательства. Запись манифеста атомарна и разрешена только
после полного охвата, проверки схемы и повторного разбора архива ответов.
Архив первой полной сверки сохранён в `research/price-sync-initial-evidence.tar.gz`.
Исходные исторические цены сохранены отдельно в
`data/price-migration-baseline.json`; восстановление этих двух исходных полей
должно давать прежнюю контрольную сумму всего каталога. Так проверяется,
что синхронизация не изменила названия, описания, изображения, отделки, URL и единицы.

## GitHub Actions

`Synchronize official catalogue prices` (`sync-prices.yml`) запускается ежедневно
в 02:17 UTC, а также вручную кнопкой Run workflow. График GitHub может задерживаться.
Лимит выполнения — 90 минут, одновременно работает один запуск синхронизации.
Он проверяет парсер, сверяет весь каталог, собирает сайт, проверяет данные,
все отображения цен и ссылки, затем выполняет браузерные проверки заявки,
сумм, навигации, карты и анимаций. Только после успешных проверок создаёт коммит.
Если main изменился во время сверки, обычный push отклоняется: force push и
автоматической перезаписи чужих изменений нет.

После коммита вызывается существующий Pages workflow с точным SHA проверенного
коммита. Это необходимо: push от GITHUB_TOKEN сам не запускает другой workflow.
Публикация снова проходит существующий validation gate и проверяет, что проверенный SHA всё ещё является текущим main. При критической ошибке
ни sync, ни Pages не разрешают публикацию.

Артефакт `official-price-evidence-<run_id>` сохраняется также при ошибке на 30 дней.
Краткая статистика — в Actions Summary и `data/price-sync-summary.json` последнего
успешного пакета. Ошибки не включаются в число товаров без публичной цены.

Для отката восстановить предыдущий `data/prices.json` через git, пересобрать,
выполнить проверки и опубликовать обычным коммитом. Снимок исходных страниц и
резервная ветка до внедрения сохранены.
