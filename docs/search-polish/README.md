# Визуальная полировка поиска

Изменён только интерфейс поиска: мягкое появление/закрытие подсказок, акцент активного выбора, стабильное место для очистки, состояния ожидания/ошибки/пустой выдачи, активные фильтры, карточки результатов и дозированное появление новых товаров. Закрывающиеся копии неинтерактивны, скрыты от дикторов и не содержат ID. Во время обновления старые подсказки недоступны для выбора; после потери фокуса панель не открывается от отложенного ввода.

Подсветка использует безопасные текстовые узлы и существующую нормализацию только для расчёта диапазонов: `SP1009` выделяет `SP-1009`, оставляя `AL+SSS` без выделения. Несколько фрагментов, размеры, русские словоформы и разные дефисы проверяются отдельно. Алгоритм и нормализация в search.js, поисковые метаданные, products.json и цены не изменены.

Движение ограничено opacity/transform, стандартные состояния — 160–220 мс, новые видимые карточки — 260 мс (максимум восемь, предыдущие карточки сохраняются). Поддерживается reduced-motion, включая смену настройки во время работы. Постоянный will-change, новые библиотеки и серверные зависимости не добавлены.

Проверено: штатная сборка, все артикулы, существующие браузерные сценарии и 25 новых проверок интерфейса (`scripts/search_visual_checks.cjs`, включён в CI). Размеры 360/390/480/768/1440 px, клавиатура, выходные слои, быстрый ввод, очистка ожидающей выдачи, загрузка, фильтры, «Показать ещё» и отсутствие горизонтального скролла. Это браузерные проверки; физическая мобильная клавиатура и реальные устройства не тестировались.
